# UK Retail Sales Analysis

A portfolio project analysing trends in UK retail sales using official UK data, Python and Tableau.

## Project objectives

- Collect and document UK retail sales data.
- Clean and prepare the data with Python.
- Explore long-term trends, seasonality and changes in retail categories.
- Compare store-based and online retail performance.
- Develop statistical or forecasting models where appropriate.
- Create a Tableau dashboard to communicate the main findings.
